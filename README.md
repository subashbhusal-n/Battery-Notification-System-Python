# 🔋 Battery Notification System

A simple Python utility that monitors your laptop's battery status and sends desktop notifications based on the current battery percentage and charging state.

## ✨ Features

- 🔋 Displays the current battery percentage
- ⚡ Detects whether the device is charging
- 🔔 Sends desktop notifications
- ⚠️ Alerts when the battery reaches a low level
- 🔌 Notifies when the battery is fully charged
- 🐍 Built entirely with Python
- 💻 Lightweight and easy to customize

## 🛠️ Technologies Used

- Python
- `psutil` — Battery status monitoring
- `plyer` — Desktop notifications
